# Radar SECTIES

Clipping diário de ciência, tecnologia, inovação e ensino superior da SECTIES-PB e da FAPESQ.

Site: https://radarsecties.github.io

Este repositório guarda só o site publicado (`index.html`, `capa.png`, `whatsapp.txt`) e o histórico (`edicoes/`, `data/`, `doe/`). Todo o resto do Radar está dentro da rotina `.github/workflows/doe.yml`, que roda sozinha às 7h05 e às 8h20. Para atualizar o Radar, troque o conteúdo desse arquivo.
