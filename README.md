# Radar SECTIES

Clipping diário de ciência, tecnologia, inovação e ensino superior da SECTIES-PB.

Site: https://radarsecties.github.io

- `edicoes/`: uma edição por dia, em JSON
- `ferramentas/modelo.html`: modelo da página
- `ferramentas/montar.py`: monta o `index.html` (14 edições mais recentes), a `capa.png` do dia e o `whatsapp.txt`
- `ferramentas/curiosidades.json`: banco da seção Física de bolso
- `ferramentas/fontes/`: fonte Arimo (compatível com Arial, licença Apache 2.0) usada na capa
